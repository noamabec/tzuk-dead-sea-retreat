# צוק · מתחם אירוח מעל ים המלח

אתר תדמית עם מנוע הזמנות למתחם אירוח במצוקי דרגות. עברית (RTL) ואנגלית (LTR, תחת `/en/`).

## הרצה מקומית
המודולים של JavaScript לא עובדים מ-`file://`, ולכן צריך שרת מקומי:

- עם Node: `npx serve .`
- בלי Node (Windows): לחיצה כפולה על `פתיחת-האתר.bat`, או `powershell -File serve.ps1 -Root . -Port 8821`

## מבנה
- `index.html` ועמודי HTML בעברית בשורש, והגרסה האנגלית ב-`en/`
- `js/layout.js`: האדר, פוטר וכפתורים צפים לפי שפה
- `js/data.js`: יחידות, מחירים, תוספות, המלצות וזמינות
- `js/datepicker.js`: לוח השנה של האתר
- `js/pages/`: עמוד יחידה, מסלול הזמנה, גלריה והמלצות
- `css/styles.css`, `css/pages.css`

## תוכן
התמונות נוצרו ב-AI. הטקסטים, המחירים, הזמינות וההמלצות הם תוכן לדוגמה. הטקסטים המשפטיים הם דוגמה בלבד, ונדרשת בדיקה משפטית לפני שימוש אמיתי. פונטי Fb מורשים לשימוש בווב לפי דומיין.
